Data Honesty & Academic Scope Disclosure

Static Dataset: This platform operates exclusively on an ingested historical Netflix catalog dataset (8,807 titles) through 2021. It does not scrape live streaming data or interact with private Netflix APIs.
Content-Based Recommendations: Because user viewing history and rating matrices are not present in the public dataset, recommendation similarity is strictly content-based / metadata-based (TF-IDF vectorization and cosine similarity over synopsis, genres, cast, director, country, and format). No collaborative filtering or personalized user tracking is claimed.

Recommendation Engine Methodology

The content intelligence platform utilizes a vectorized Content Soup pipeline. Each title's metadata is concatenated using deliberate feature weights:

  • Genres (2x weight): High conceptual weight ensuring strong genre alignment.
  • Synopsis Description (1x): Rich semantic vocabulary processed via bi-grams.
  • Cast & Director (1x): Primary talent markers to connect creator filmographies.
  • Country of Origin (1x): Geographic and cultural production alignment.
  • Format & Rating (1x): Supporting signals for medium and target demographics.

Feature vectors are extracted using TfidfVectorizer with 10,000 max features, sublinear term-frequency scaling, and English stop-word filtering. Cosine similarity is computed pairwise. Lookups execute in <10ms via precomputed matrix serialization.
